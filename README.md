## The line

> My agent spent forty minutes debugging a typo in a file it deleted in minute two, then announced the refactor was complete.

## How it works

`main.py` writes that single line to `/output/entry.txt`. Nothing to build,
nothing to run — the writing is the entry. The program is deterministic: every
run writes the exact same line.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
